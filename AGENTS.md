# Working on Penny

- Read README.md and docs/ARCHITECTURE.md before changing product behaviour.
- Keep photos on the device. Cloud text sharing must remain an explicit choice.
- Never replace a failed reading with a fixture; samples require a separate user action.
- Preserve keyboard operation, visible focus, speech/text parity and reduced-motion support.
- Treat banking data and actions as simulations. Do not invent adoption or accessibility claims.
- Run the relevant checks from CONTRIBUTING.md. Review accessibility baselines before migrating them.
- Keep secrets in ignored environment files. Do not include personal documents in fixtures or screenshots.
