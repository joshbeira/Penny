Penny now has a native Kotlin Android app and a private saved-letter library on both Android and the web.

**[Open the web app](https://joshbeira.github.io/Penny/)** · **[Android installation guide](https://github.com/joshbeira/Penny/blob/main/docs/ANDROID.md)**

### What’s new

- **Android:** Jetpack Compose, bundled offline OCR, camera/photo picker, editable text, offline device speech and adjustable reading controls.
- **Your letter library:** explicitly save reviewed text, search, favourite, reopen, export and delete on either platform. Libraries stay on their own device.
- **Accessible practice:** spoken account overview, sound cues, haptics, confirmations and verifiable receipts using clearly labelled sample banking data.
- **Voice navigation:** on-device Android commands where supported; existing browser voice navigation remains available.
- **Web improvements:** OCR correction, paste input, text size and speech speed, more resilient speech, storage-failure handling and installation help.
- **Engineering:** Android build, lint, unit and airplane-mode device tests; expanded browser and accessibility coverage; signed distribution with checksums.

### Install Android

Download **penny-2.0.0.apk** below on an Android 8.0+ phone and open it. Android may ask you to allow installation from your browser. The `.aab` is a publishing artifact for developers; use the `.apk` to install directly.

No account or network connection is needed for native recognition. Read-aloud needs an installed offline English voice. Offline voice commands require supported Android 12+ devices. This is a public beta distributed through GitHub, not a Play Store listing.

### Privacy and scope

Neither app uploads photos. Saved text remains in the current device/browser unless you export or share it. Number masking can hide dates and miss sensitive details; review the text. AI summaries are an optional web-server feature and are disabled on the public Pages deployment. Banking actions are simulations.

Try a sample letter, save it, reopen it, and [tell me what worked or got in your way](https://github.com/joshbeira/Penny/issues/new?template=feedback.yml). Public reports should contain synthetic examples, not personal letters.
