# Roadmap

The order below prioritises evidence from real use. Unchecked work is planned, not an available capability.

## Available in v1.1

- [x] Local English OCR with errors and explicit sample reading
- [x] Device speech, text export and clear controls
- [x] Explicit consent for optional AI text summaries
- [x] Accessible navigation and automated route checks
- [x] Installable PWA with bundled OCR assets
- [x] Serialised hash-chain receipts, export and deletion
- [x] Feedback templates and a documented beta study

## Next: validate the reader

- [ ] Complete five consenting usability sessions and publish anonymised findings
- [ ] Validate TalkBack, VoiceOver and NVDA flows with human testers
- [ ] Test camera framing and OCR performance on older phones
- [ ] Improve misrecognition recovery based on observed failures
- [ ] Add an accessible feedback route that does not require a GitHub account

## After validation

- [ ] Add crop/rotate and user-editable redaction before sharing
- [ ] Add durable rate limits and operational monitoring before enabling public paid AI
- [ ] Evaluate PDF and additional-language support with representative documents
- [ ] Coordinate receipt updates across tabs if the sandbox develops into a larger workflow

Real banking integrations, financial advice and automated scam reporting are outside the current product scope.
