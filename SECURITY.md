# Security

Please do not put secrets, personal letters or exploit details into a public issue.

Use the repository's **Security → Report a vulnerability** control when available. Otherwise contact the maintainer through the contact details on [the GitHub profile](https://github.com/joshbeira) to arrange a private report. No response-time guarantee is currently offered.

Include the affected version, a reproducible example with synthetic data, expected impact and suggested mitigation. The latest release is the actively maintained version.

Penny is a beta reader and interaction playground. Numeric masking is not guaranteed redaction. Receipt hashes are not signatures. Public deployments should leave paid AI disabled until platform rate limits and provider budgets are configured. See [architecture](docs/ARCHITECTURE.md) and [privacy](docs/PRIVACY.md) for the current trust boundaries.
